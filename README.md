# K뷰티 하노이 — 한국 여성 화장품 직구(구매대행) 플랫폼

하노이 거주자를 위한 한국 여성 화장품 구매대행 서비스입니다.
쿠팡 가격을 연동하고, **상품명만으로 배송 무게를 추정**해 **1kg당 요율** 기반
국제배송비와 베트남 수입세까지 포함한 랜딩코스트를 즉시 계산합니다.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 로직 테스트 50개
npm run build
```

API 키가 없어도 내장 예시 데이터로 전체 기능이 동작합니다.

---

## 1. 무엇을 해결하는가

구매대행의 견적은 **결제 시점에 무게를 모른다**는 문제가 있습니다.
쿠팡 상품 페이지에는 배송 무게가 없고, 상품명에 `50ml` 같은 **내용물 용량**만 적혀 있습니다.
실제 항공 운임은 `내용물 + 용기 + 포장`의 총 무게로 매겨집니다.

이 프로젝트는 그 간극을 계산으로 메웁니다.

```
상품명 "토리든 다이브인 세럼 50ml"
  → 파싱      : 용량 50ml, 수량 1
  → 제형 판별  : 앰플/세럼 (밀도 1.03 g/ml)
  → 내용물    : 50 × 1.03        =  51.5g
  → 용기 공차  : 아크릴 펌프용기    =  68.1g
  → 완충재    :                  =  12.0g
  → 실무게                        = 131.6g   (실측 참고값 130g, 오차 +1.2%)
  → 부피무게   : 260cm³ ÷ 6000    =  43.3g
  → 청구무게   : max(실무게, 부피무게)= 131.6g
```

참고 제품 8종 대비 추정 오차는 **-8.0% ~ +7.9%** 입니다 (`npm test` 로 회귀 검증).

## 3. 쿠팡 가격 연동

### 동작 방식

`lib/coupang/source.js` 가 **어댑터**입니다. 환경변수 유무로 소스가 자동 전환됩니다.

| 소스 | 조건 | 동작 |
|---|---|---|
| `partners` | `COUPANG_ACCESS_KEY` + `COUPANG_SECRET_KEY` 설정 | 파트너스 Open API 실시간 조회 |
| `seed` | 키 없음, 또는 API 장애 + 캐시 없음 | 내장 예시 데이터 |

현재 소스는 화면 우측 상단 배지(`쿠팡 실시간` / `예시 데이터`)에 항상 표시됩니다.

### "실시간"의 실제 의미

파트너스 API에는 호출 제한이 있어 **사용자 요청마다 조회할 수 없습니다.**
따라서 TTL 캐시(기본 10분) + stale-while-revalidate 로 **준실시간**을 구현했습니다.

- 캐시가 신선하면 즉시 응답 (API 호출 없음)
- 동일 키 동시 요청은 1회 호출로 합쳐짐 (thundering herd 방지)
- 갱신 실패 시 최대 1시간까지 낡은 값으로 서비스 지속
- 화면에는 항상 `기준 시각`을 함께 표기

> ⚠️ 인메모리 캐시는 서버리스에서 인스턴스마다 분리됩니다.
> 프로덕션에서는 `lib/coupang/cache.js` 를 Redis / Vercel KV 로 교체하세요.

### 키 설정

```bash
cp .env.example .env.local
# COUPANG_ACCESS_KEY / COUPANG_SECRET_KEY 입력
```

`SECRET_KEY` 는 서버 번들에만 포함됩니다. 빌드 후 다음으로 확인할 수 있습니다.

```bash
grep -r "COUPANG_SECRET_KEY\|HmacSHA256" .next/static/   # 결과가 없어야 정상
```

## 4. 여성 화장품 필터

쿠팡 뷰티 카테고리에는 남성용품·헤어·바디·미용기기가 섞여 있어 3단으로 걸러냅니다.

1. **남성용 키워드 제외** — 남성 / 옴므 / 포맨 / 쉐이빙 …
2. **비화장품 제외** — 드라이기 / 샴푸 / 바디워시 / 생리대 …
3. **서브카테고리 화이트리스트** — 스킨케어·클렌징·마스크팩·선케어·베이스·아이·립·네일·향수

### 분류 순서가 중요합니다

서브카테고리는 **배열 순서가 아니라 `matchPriority` 순서로** 매칭합니다.
스킨케어의 `크림`·`오일`·`토너` 같은 일반 키워드가 먼저 걸리면 오분류되기 때문입니다.

| 잘못된 결과 | 원인 | 해결 |
|---|---|---|
| 클렌징오일 → 스킨케어 | 스킨케어 `오일` 이 먼저 매칭 | 클렌징(20) < 스킨케어(90) |
| 선크림 → 스킨케어 | 스킨케어 `크림` 이 먼저 매칭 | 선케어(10) < 스킨케어(90) |
| 토너패드 → 스킨케어 | 스킨케어 `토너` 가 먼저 매칭 | 마스크팩(30) < 스킨케어(90) |
| 쿠션팩트 → 마스크팩 | 마스크팩 `팩` 이 너무 일반적 | `팩` 키워드 제거 |
| SPF 표기 쿠션 → 선케어 | `SPF` 가 너무 약한 신호 | `SPF` 키워드 제거 |
| 립 팔레트 → 아이메이크업 | 아이 `팔레트` 가 먼저 매칭 | 립(55) < 아이(60) |

### 오탐 대응

브랜드명이 제외 키워드를 포함하는 경우가 있습니다.
(예: 여성 향수 브랜드 **포맨트**가 남성 키워드 `포맨` 에 걸림)

`config/catalog.js` 의 `BRAND_SAFELIST` 에 브랜드명을 추가하면 해당 브랜드는
제외 키워드 검사에서 보호됩니다.

> 자동 분류만으로 100%를 걸러낼 수는 없습니다.
> API 응답에는 제외 사유(`filterStats`, `rejectedSample`)가 함께 담기므로,
> 운영자 검수 큐를 붙여 하이브리드로 운용하는 것을 전제로 설계했습니다.

## 5. 배송비 — 1kg당 요율

```
청구무게 = max(실무게, 부피무게)
         → 최소 청구무게(0.5kg) 미만이면 최소값 적용
         → 0.5kg 단위로 올림
배송비   = 구간 요율(원/kg) × 청구무게 + 지역 할증 + 위험물 할증
```

`config/shipping.js` 기본값:

| 구간 | 1kg당 |
|---|---|
| ~2kg | 13,000원 |
| 2~5kg | 11,500원 |
| 5~10kg | 10,000원 |
| 10~20kg | 9,000원 |
| 20kg~ | 8,200원 |

- 부피무게 = `가로×세로×높이(cm) ÷ 6000`
- 포장 박스 250g 은 **배송 건당 1회만** 가산
- 하노이 시내 0원 / 외곽 +20,000원 / 근교 군지역 +45,000원

### 항공 제한 품목

한국 화장품 직구에서 향수 비중이 커서 별도로 처리합니다.

- **운송 불가** — 네일리무버·아세톤·헤어스프레이 등 (장바구니 담기 차단)
- **수량 제한 + 할증** — 향수·오드퍼퓸·바디미스트 (건당 2개, 개당 8,000원 할증)

할증은 견적 명세에 **별도 행으로 분리 표시**됩니다.
`2kg × 13,000원`이라 적어놓고 34,000원을 청구하면 분쟁이 생기기 때문입니다.

## 6. 베트남 수입세 (필수 반영 사항)

> ⚠️ `Decision 01/2025/QD-TTg` 로 `Decision 78/2010/QD-TTg` 가 전면 폐지되어
> **2025-02-18 부터 100만 VND 미만 특송화물 면세 제도가 사라졌습니다.**
> 금액과 무관하게 모든 수입 건에 관세·VAT가 부과됩니다.

```
CIF  = 상품가 + 국제운임 (+보험료)
관세 = CIF × 관세율
VAT  = (CIF + 관세) × VAT율
```

`config/taxes.js` 의 세율은 **설정 가능한 기본 가정값**입니다.
실제 세율은 HS 코드·원산지증명(VKFTA/AKFTA) 적용 여부·세관 판단에 따라 달라지므로,
**운영 전 반드시 관세사 검토를 거쳐 값을 확정하세요.**

면세 제도가 부활하면 `deMinimisVnd` 값만 되돌리면 됩니다.

## 7. 구매대행 모델 전제

- 고객 주문 → 당사가 쿠팡에서 대신 구매 → 하노이 배송
- 상품 소유권은 고객에게 있고, 당사는 **대행 수수료**를 받습니다
- 개인 사용 목적 반입이므로 화장품 신고(CPN) 대상이 아닙니다
  - 단, 동일 상품 과다 수량은 상업적 반입으로 간주되어 통관이 보류될 수 있어
    `config/taxes.js` 의 `personalUse` 기준으로 경고를 표시합니다
- 무게는 추정치이므로 **결제액은 확정이 아닙니다**
  - 화면에 정산 범위(`268,528원 ~ 276,621원`)를 함께 노출
  - 한국 창고 입고 후 실측하여 차액을 추가 청구/환불로 정산

## 8. 알려진 제약

| 항목 | 내용 |
|---|---|
| 파트너스 약관 | 제휴 데이터를 자체 판매 카탈로그로 쓰는 것은 프로그램 목적 밖일 수 있습니다. 가격 소스를 어댑터로 분리해 두었으므로 문제 시 `source.js` 만 교체하면 됩니다 |

| 무게 추정 | 세트·기획 구성처럼 상품명에 규격이 없는 경우 오차가 커집니다(신뢰도 `낮음` 표기) |
| 세율 | 관세사 검토 전까지는 가정값입니다 |
| 결제·주문 | 견적 산출까지 구현되어 있고, 실제 결제 연동(PG)과 주문 관리는 포함되지 않았습니다 |
