3. (같은 날 앞서) **「읽기 기기 없음」 결과를 6시간 기억하던 것 → 10초 + 기기가 살아나면 바로 무시** — 크롬을 켠 뒤에도 같은 상품이 「가격만」으로 남던 원인.

시험 도구 쪽: 가격이 글자에서 입력칸으로 바뀌어 옛 검사식 2곳(확장 e2e 4c, 서버 크롬 2번)을 갱신. PC 하네스는 중복 방지 규칙 때문에 데이터를 비우고 돌려야 함(메모).

## 확인 못 한 것 — 실서버·바깥 서비스

1. **실서버 크롬이 실제 쿠팡 화면을 읽는가** (쿠팡의 서버 IP 차단 여부). 크롬이 살아 있는 것까지 확인. 폰에서 링크를 넣은 뒤 `/api/worker/status` 의 `recent` 로 판정 — 「차단됨」이면 사무실 PC 크롬 켜기(자동 인계) 또는 `KB_WORKER_PROXY`.
2. **쿠팡 그림 서버 사진이 사이트에서 보이는가** — 이 공간은 그 서버가 막혀 가짜 그림으로만 확인. 안 보이면 우리 서버가 대신 받아 보여주는 방식으로 바꿈(반나절).
3. Inter 글꼴(구글) — 여기서는 막힘. 못 받아도 기기 글꼴로 정상 표시되는 것은 확인.
4. 안드로이드 공유 목록(홈 화면에 추가한 뒤 「베트남 직구」로 공유) — 실제 폰 필요.
5. 카카오 오픈채팅 링크가 실제로 열리는지.
6. 텔레그램 알림 — 서버에 토큰이 없으면 건너뜁니다(정상).
