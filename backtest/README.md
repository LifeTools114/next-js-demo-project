# 공시 기반 전략 백테스트 (2022~2025)

DART 공시(기본값: 단일판매·공급계약체결)를 보고 다음 거래일 시가에 매수하는
전략을 2022-01-01 ~ 2025-12-31 구간에서 검증하는 프로그램입니다.
수수료·거래세·슬리피지를 전부 차감하고, 코스피 단순보유와 비교합니다.

## 준비

1. Python 3.11+ 설치
2. 의존성 설치:
   ```bash
   pip install -r backtest/requirements.txt
   ```
3. DART 오픈API 키 무료 발급: https://opendart.fss.or.kr (가입 → 인증키 신청, 즉시 발급)

## 실행

프로젝트 루트에서:

```bash
export DART_API_KEY=발급받은키
python3 -m backtest.run
```

최초 실행은 공시 4년치 + 종목별 주가를 내려받느라 수십 분 걸릴 수 있습니다.
전부 `backtest/cache/`에 저장되므로 두 번째부터는 수 초 안에 끝납니다.

규칙을 바꿔서 재실행:

```bash
python3 -m backtest.run --hold-days 3 --stop-loss -0.03 --take-profit 0.15
python3 -m backtest.run --start 20220101 --end 20221231   # 하락장만 따로
```

공시 키워드, 동시 보유 종목 수, 비용, 유동성 필터 등 나머지 규칙은
`backtest/config.py`에서 수정합니다.

## 기본 전략 규칙

| 항목 | 기본값 |
|---|---|
| 시그널 | "단일판매"/"공급계약" 포함 공시 (정정·해지·철회 제외) |
| 진입 | 공시 다음 거래일 시가 (+슬리피지 0.3%) |
| 청산 | 손절 -5% / 익절 +10% / 5거래일 경과 시 종가 |
| 자본 | 1,000만원, 동시 최대 5종목 (종목당 자본의 1/5) |
| 유동성 필터 | 공시일 거래대금 1억원 미만 종목 제외 |
| 비용 | 수수료 0.015%×2 + 거래세 0.20% + 슬리피지 0.3%×2 |

## 결과물

- 콘솔: 총수익률, 연환산, MDD, 승률, 손익비, 연도별/월별 수익률, 코스피 대비 초과수익
- `backtest/output/trades.csv` — 전체 거래 내역
- `backtest/output/equity.csv` — 일별 평가액 곡선
- `backtest/output/report.txt` — 리포트 사본

## 엔진 검증

주가 데이터 없이 합성 데이터로 체결 로직(손절/익절/기간만료/비용/보유수 제한)을 검증:

```bash
python3 -m backtest.test_engine
```

## 결과 해석 시 주의 (중요)

- **생존 편향**: 상장폐지된 종목은 주가 데이터가 없어 제외됩니다. 실행 로그에
  제외 종목 수가 표시되며, 많을수록 실제 성적은 리포트보다 나쁩니다.
- **2025년 함정**: 2025년은 코스피 +75%의 예외적 상승장입니다. 반드시
  연도별 수익률에서 2022년(하락장)·2023~2024년(횡보장) 성적을 따로 보고,
  "코스피 대비 초과수익"을 기준으로 판단하세요.
- **체결 한계**: 상한가 직행, 호가 공백 등 실전 체결 불가 상황은 슬리피지
  가정으로만 근사됩니다. 백테스트가 좋아도 실전은 이보다 낮게 잡아야 합니다.
- 백테스트 수익 = 미래 수익 보장이 아닙니다. 이 도구의 목적은 "이 전략이
  최소한 말이 되는지"를 비용 포함으로 확인하는 것입니다.
